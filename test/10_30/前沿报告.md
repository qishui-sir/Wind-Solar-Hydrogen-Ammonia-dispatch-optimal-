# 经济—更新次数帕累托前沿

> 数值来源：`src/cache/O1_economic_threshold_partition21_cache.mat`。该缓存含 90 条带可行解的记录，其中 47 条经主程序原矩阵重核。本文表格由缓存导出，正文解读为人工撰写。
> 基准量：参考成本下界 $L_C=31\,747\,614.090131$ USD，参考可行上界 $U_C=31\,747\,636.626430$ USD，年产量 $Q=80\,000$ t/a，跟踪总带宽 $\varepsilon_h=0.01$。

## 1. 问题与口径

对固定更新上限 $k$，记

$$F(k)=\min_{x\in\mathcal X,\,N(x)\le k} C(x),\qquad \Delta C(k)=\frac{F(k)-L_C}{Q}.$$

前沿即 $(k,\Delta C)$ 的单调包络。三点口径必须说明：

1. **每条记录给的是一个区间，不是一个点。** 表中成本 $C$ 是已核验可行解，满足 $C\ge F(k)$；同次求解的 Gurobi 全局界 $C_L$ 满足 $C_L\le F(k)$。因此 $F(k)\in[C_L,C]$。除个别点外，本表大部分点的区间宽度与溢价同量级（见第 6 节），故这条线应称为**经验上包络**，不能写作精确 $F(k)$。
2. **横轴用实际更新次数 $K$，不用采样上限 $k$。** 求解 `min C s.t. N ≤ k` 时，最优解未必用满 $k$（例如 $k=550$ 得到 $n=541$）。若用 $k$ 作横轴，会把所需预算高估。
3. **预算帽与主程序同口径。** 本表预算帽为 $L_C+\delta Q$，与主程序严格帽 $\tau_{\mathrm{sat}}=L_C+\Delta$ 完全一致；主程序另有宽松帽 $\tau_{\mathrm{fail}}=U_C+\Delta$，本表不使用。

## 5. 前沿形状

![经济—更新次数帕累托前沿](前沿曲线.png)

横轴为实际更新次数 $K$（对数），纵轴为溢价 $\Delta C$（USD/t，对数）。灰点为缓存中的可行见证，蓝线为单调包络。绿色虚线为 $\delta=0.5$ 主结果的认证下界 408——**它只在该经济预算下有效，不适用于更高溢价的左侧区段**。点线为 $\delta=0.5$ USD/t。

读法：

- **K_eco 上界为 486**：固定 $k=486$ 的 7200 s 求解得到 486 次、成本 31,772,848.004（溢价 0.3154 USD/t），比 $\delta=0.5$ 的经济帽 31,787,614.09 低约 14,766 USD，故 $K_{\mathrm{eco}}\in[408,486]$。
- **486—806 段已被填满**：550 次（0.0809）、650 次（0.00998）把原先 250 次的空档拆成 64、100、156 三格，全部落在 200 以内。
- **约 1510 次达到已核验的最低成本**：溢价 0.000072 USD/t（5.7 USD/年），比原先 4029 次的参考解（0.000282）还低 16.8 USD/年；该点是全部记录中唯一对偶间隙接近于零的（0.03 USD）。
- **陡升发生在 486 次以下**：445 次（2.899）、405 次（5.586）；470 次（1.340）与 486 次（0.3154）之间还有 16 次的细格。
- **888—1510 是三级平台**：888（0.0092）→1136（0.00099）→1270（0.00054）→1510（0.00007），间隔 248、134、240，其中 248 与 240 是仅剩的两处超过 200 的间隔，且均为饱和平台（$k=900$—$1100$ 全部返回 888，$k=1300$—$1450$ 全部返回 1270）。

## 6. 证据边界

1. **除 1510 外，各点对偶间隙与溢价同量级。** 例如 486 点溢价 0.5041、间隙 0.5041；888 点溢价 0.0092、间隙 0.0093；1136 点溢价 0.00099、间隙 0.0010。只有 1510 点的间隙为 0.0000004。因此**不要把 487 的 0.4917 当成 $F(487)$ 的精确值**；作为"$\delta=0.5$ 预算下可实现的上界"是安全的（余量 662.7 USD）。
2. **两处宽间隔是饱和平台，不是缺证据。** $k=900$—$1100$ 五次采样全部返回 $n=888$，$k=1300$—$1450$ 全部返回 $n=1270$，再加 $k$ 不会产生中间点。
3. **486—541 的细结构不可信。** 该段相邻跌幅只有 30—1,342 USD（0.0004—0.0168 USD/t），而每点间隙约 37,800—40,300 USD；信号只占间隙的 0.08%—3.4%。只有大约 0.47—0.50 USD/t 的平台水平是可信的。
4. **热启动的作用。** 它只提供一个初始可行解（初始上界），不缩小可行域，也不决定最终解；若最终解与起点相同，说明该时限内未找到更优解。
5. **缓存中的旧点不进入包络。** 529、590、1544、2000、3082、3815、4029 等均被更小 $K$ 且更低成本的点支配，已由下包络自动剔除。

## 7. 复现

环境：MATLAB R2026a、Gurobi 13.0、4 线程、Gurobi `Seed=0`、`MIPGapAbs=1` USD。前置条件：先运行主程序生成经济阈值缓存，否则脚本会在缺缓存时终止。

```matlab
cd test/10_30
run('run_sampling.m')   % 逐 K 采样；会通过 Calculate_K 写入主缓存
run('run_frontier.m')   % 按 delta 网格复核并输出报告
```

`run_sampling.m` 顶部的 `K_list` / `T_list` 即采样网格与单点时限；`run_frontier.m` 负责按 $\delta$ 网格复核与汇总输出。第 3 节的包络表直接由缓存导出（按 $K$ 升序取成本创新低的点），不依赖任何求解。第 5 节的图由同一张表按单调包络绘制，绘图代码独立于本仓库的 MATLAB 脚本。
