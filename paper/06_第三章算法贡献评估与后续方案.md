## 1. 负责人判断

**当前算法足以支撑一章内容完整、数学口径清楚的方法章；现有证据尚不足以把“通用高效新算法”确立为论文的首要贡献。** 这不等于项目不能形成论文，也不意味着必须先把 Keco 精确求到一个整数才能投稿。关键在于论文承诺什么，以及证据是否支持该承诺。

建议将第三章命名为“经济容许损失下最低设定值更新需求的识别与认证”，并以能源系统问题为主线。当前最有价值的区别是，既给出一条满足经济预算的少更新调度，又用下界排除一部分更低更新预算，从而分开“已经找到的方案”和“系统最低需求”。这比只展示成本优先与少更新两条轨迹更有解释力。

目前可以主张的是一个面向本问题的可复核计算框架。是否存在文献层面的首创增量，仍需把完整数学形式与最邻近工作逐项比较；源码和一个算例不能完成这一证明。

## 3. 当前算法究竟是什么

实际链路是

> 完整年度成本问题 → 参考成本括号 → 双经济帽 → 原年度见证给上界 → 根 LP 固定价格引导的层次分区整数松弛给下界 → 原域和证书复核 → 返回 Keco 区间。

它不是当前仍在执行的 DW、分支定价、ADMM 或次梯度迭代算法。旧模块的名字、兼容字段或配置注释不能作为执行证据。尤其是 `economic_proof_mode='full'`，不能解释为当前分区子问题保留了所有设备整数。

| 事实 | 当前实现 |
|---|---|
| 参考成本求解 | 无缓存时由 `intlinprog` 求解 |
| 分区求解 | Gurobi 根 LP 与局部 MIP |
| 分区根模型 | 原年度矩阵，含宽松经济帽；放松全部整数 |
| 局部整数 | 只恢复 HB 更新变量 z，其他原整数连续放松 |
| 价格 | 完整根 LP 全行价格，合法符号投影后固定使用 |
| 分区层级 | 默认 96 h、192 h，共 92 与 46 块 |
| 储氢与循环边 | 保留全部 8761 状态与 8760 HB 循环边；跨块行整行对偶化 |
| 父子传递 | 子块下界加新局部行常数和有限盒残差修正，作为父块地板 |
| 年度合并 | 块内取最好有效地板，块间求和；层间取最大值；最后年度取整 |
| 上界来源 | 通过当前原模型核验的年度见证；不来自局部解拼接 |
| 默认结束 | 完整分区扫描且有有效上界时返回；上下界未相等仍保留区间 |

## 5. 为什么目前还不宜把算法作为首要贡献

### 5.1 组成工具的已有性，与本问题集成的价值不同

把一个目标放入约束属于 ε 约束方法；跨块约束的价格松弛属于拉格朗日方法。这两类工具已有成熟文献，不能以换一个能源场景证明其为新算法。[Mavrotas, 2009](https://www.sciencedirect.com/science/article/pii/S0096300309002574)、[Guignard, 2003](https://link.springer.com/article/10.1007/BF02579036)。

高时间分辨率能源模型中也已有按时间分解并求解拉格朗日对偶的工作。例如 Granfeldt 等讨论电力投资与储能时序，使用变量分裂及乘子算法。它与本项目的固定容量、计数目标和证书设计不同，说明一般“年度时间分解＋价格”不能单独构成新颖性。[出版社全文](https://link.springer.com/article/10.1007/s00291-023-00736-w)。

本项目值得进一步查证的增量是，将不精确参考成本的双帽判断、HB 设定值计数、同模型有限盒修正与层次地板继承连成可复核链条。当前应称“问题定制的认证方法”，是否具有足够新颖性需要邻近方法逐式对照，不能现在宣布首创。

### 5.2 已有实例证据，但尚未证明相对竞争方法的优势

现有记录说明本实例获得了有用的下界，不能替代与直接年度 MILP、根 LP、单层分区和无继承分区的公平对照。281.8 秒使用已有参考和 487 调度，不能同另一个方法从零生成这些信息的总耗时比较。没有对照时，无法回答“收益来自分区结构、HB 整数、继承、更多计算时间，还是更好的先验信息”。

这首先是证据缺口，不是已经证明方法没有优势。必要的下一步是小而明确的消融和同预算比较，不是再堆很多方法名称。

### 5.3 当前证书没有完整处理年度非凸结构

根 LP 价格在恢复局部 HB 整数后保持不变，其对整数分解问题未必是好的价格。AEL 等整数放松以及跨块储氢、年度经济与产量耦合也可能带来结构间隙。另一方面，26 个 H192 块限时未闭合，又说明现有下界可能仍受局部求解精度限制。

这两种限制需要分开诊断。仅凭局部求解限时，不能断言继续加时必然显著提升；仅凭区间停滞，也不能断言固定价格已到理论极限。当前没有一般性收敛到精确 Keco 的保证。

### 5.4 单一年度和单一经济预算不足以建立普适算法结论

目前正式证据主要来自一个 2022 年基准、一个容许损失和既定设备配置。未给出多年份、容量/产量变化、不同问题规模下的优势与失效边界。即使把单个区间收敛得更紧，也不能代替这些证据。

### 5.5 少更新的工程收益仍需准确定位

现有对比显示，少更新可能伴随更多购电和弃电，并把运行压力转移给其他设备。它可支持“经济预算内的运行复杂度权衡”，尚不能直接支持寿命、疲劳、排放或全系统收益改善。购电费用已在成本中，不能再把同一购电变化当作独立货币损失重复计算。

绿氨柔性与调节频率本身已有研究，因此“研究频率如何影响成本”仍需收窄增量。[ECM 的多频率柔性调度研究](https://www.sciencedirect.com/science/article/abs/pii/S0196890423013225)已经涉及调节频率等特征；本次仅核到其摘要与 highlights，不能据此声称它没有任何最低需求问题。更有潜力的区别是预算内的最低需求认证、可避免更新的量级，以及储氢和电网条件如何改变这一需求。

### 5.6 与目标期刊的关系

ECM 官方范围明确要求，以优化为核心的论文应支撑能源主题的实质性贡献，仅应用或比较已有方法、提出小变体通常不足以单独成立。[官方范围](https://shop.elsevier.com/journals/energy-conversion-and-management/0196-8904)。这支持将算法服务于能源问题，但不意味着必须发明全新数学算法。Energy 和 Applied Energy 的能源系统范围也不能用来保证接收。[Energy](https://shop.elsevier.com/journals/energy/0360-5442)、[Applied Energy](https://shop.elsevier.com/journals/applied-energy/0306-2619)。

## 6. 后续路线的优先级

### 路线 A　以能源系统认识为主贡献，优先推荐

保留当前第三章作为计算支撑，把新增工作集中到以下证据链。

1. **成本—更新预算关系。** 计算若干有判别力的 `F(k)`，每点报告成本上下界、真实使用的更新次数和原域残差。4029、4000、3900……487 的扫描可以建立初始资料，但平坦区间不必反复精算，在经济帽附近或曲线转折处再加密。固定 K 成本求解必须取消达到经济帽即提前接受的停止逻辑。已有 487 调度可作为所有更大预算的共同可行上界，因此不能接受更大 k 却只有更差上界的表面“前沿”，应维护跨 k 的有效包络，并保留每点原始结果。
2. **最低需求对经济预算的变化。** 对少量预设 δ 重新建立双帽及区间，而非把一条可行曲线当作 Keco。除单调性外，应回答阈值量级、转折位置与不确定范围，不能把可行域包含导致的单调性当新发现。
3. **储氢与补氢、电网机制。** 保持其余条件和产量一致，分别改变储氢可用容量、补氢能力、电网边界并重新优化。只有受控变化后阈值区间有可区分移动，才有依据谈替代和瓶颈。区间重叠较大时先收敛相关算例，不能用单条库存触底轨迹作因果结论。
4. **代价转移与适用边界。** 同时报告成本、购售电、弃电、AEL 启停、更新幅度和驻留时间。不强求所有指标改善，说明低更新需求以何种系统条件和额外资源交换而来。

该路线的核心结果应放在结果与机制章节，而不是继续扩写第三章。算法间隙是否足够小，应由这些能源结论能否在区间不确定性下成立判断，没有适用于三个期刊的统一百分比门槛。

### 路线 B　如果坚持以算法为主贡献，先诊断，再只发展一个增强方向

**B0　先量化“还能从精算获得多少”，不启动新的方法盲扫。** 对当前正式上下文的每块，用其已验证局部可行点形成目标上端 \(u_j\)，与采用的下界 \(\lambda_j\) 配对。令

\[
D_H=B_H+\sum_j\phi_j^H,\qquad
V_H=B_H+\sum_j u_j.
\]

对同一价格、分区、目标和域，在适当数值保护下有 \(L_H\le D_H\le V_H\)。\(V_H\) 只是该固定分解值的上端，不是 Keco 上界。若 \(\max_H V_H\) 已不足以越过下一个计数门槛，则精确求完这些局部问题也不能使这组固定分解给出更高整数下界；应改变结构或价格。若上端仍留有可观空间，则优先精算确有机会提升年度地板的块。

现有正式下界为 407.647277668290。按 `ceil(L−1e−5)` 规则，整数下界升至 409 需要 \(L>408.00001\)，净增超过约 0.352733；升至 410 需要净增超过约 1.352733。它们是门槛计算，不是预计收益。

**B1　若局部证明缺口主导，定向精算并合法传递。** 从当前 H192 的 26 个未闭合块中，按超过已有地板的潜力与单位时间推进速度选少数块，保留完全相同的模型、价格和目标，只改变求解预算。H96 当前仅有 5 个未闭合块，不能继续照搬旧 16 报告的 16 块清单。传播时显式核对父子原始地板与目标，父层已有更强界时，子块改善可能不增加全年证书。

**B2　若结构缺口主导，再选择一个要点开发。** 优先候选是非均匀时间块或平台路径扩展，而非统一把全年全部块扩大。选择失配严重的边界，将相邻块合并，重新分类全部跨块行、更新目标和常数，并保留全年列覆盖。若选择设定值平台路径，则必须给出原模型投影等价关系、跟踪带与爬坡一致性、储氢资源联系和年度循环闭合；先在可枚举短周期上验证，再做年度少量定向试验。旧方法 09 仅有小例证据，这是一条待验证路线，不能写成已实现算法。

**B3　价格优化只能在认证 oracle 下作为另一备选，不宜与 B2 同时铺开。** 过去 11、13、18、20 已试过若干价格或支持回填配置，无明显收益。重启的前提应是 B0 证实固定价格的结构上端较低，并有清楚的新机制。可研究利用局部可行点构造对偶函数的仿射上包络、用安全全局界评价候选价格的不精确 bundle 方法。受限主问题值只能指导价格，不能直接当 Keco 下界。每个新价格必须重新计算完整年度地板；或对旧地板按 \(\min_{\ell\le y\le u}(q^{new}-q^{old})^\top y\) 作合法修正。不同目标下的局部旧界不能直接拼接。

上述 B1–B3 的数学部件也各有已有研究。算法论文需要进一步明确本问题特有的增量和可检验优势，不能仅把这些名称组合成新标题。

### 路线 B 的验收方案

先冻结共同的年度矩阵、双经济帽、参考信息、线程和初始可行调度，再比较直接计数 MILP、根 LP、H96、H192、无继承两层和最终方法。消融只去掉一个模块。报告固定时间点的安全下界、可行上界、首次到达某个整数门槛的时间和所有阶段总耗时。

对多年份或参数变体使用预先定义的算例集合，既展示收益，也保留无收益与失败算例。若只研究计数认证的增量耗时，可以共享参考与上界，但所有方法必须共享相同信息，并另列从零的总成本。首次运行与缓存恢复分别列出。完整冷启动若未执行则标为未验证，不能推算成实测。

开发文件严格按方法分开，测试通过和原件验收后才考虑主文件。每个新方法目录包含 `src/` 与 `runs/<run_id>/{models,raw,checkpoints,logs,reports}`，每个 run 至少有中文报告、机器摘要、VALIDATION 和文件哈希。`EXECUTED`、`NUMERIC_PASS`、`INDEPENDENT_ACCEPTED`、`NO_GAIN` 应分别记录，文档齐全不能代替数值验收。以上仅为后续规格，本次没有新建测试方法目录。

## 7. 当前不建议做什么

- 不将“变化次数减少约 88%”直接写成系统所需柔性减少约 88%。4029 是一条参考成本调度的计数，没有证明它是成本最优集合内必要的最少计数。
- 不为包装算法强行加入多种元启发式、ADMM 或分支定价，也不将历史不可达模块并入当前主流程图。
- 不因成本和购电略增就判定结果无价值。应回答这是可接受的运行复杂度交换，还是代价转移过大，结论由受控结果决定。
- 不在缺少设备损伤或运维数据时，把任意 \(\lambda K\) 称为真实退化成本。它可以作为偏好或盈亏平衡分析，但需要如实命名。
- 不把单点 Keco 更紧替代方法比较与能源机制验证，也不承诺某个增强方向必定大幅收敛。
