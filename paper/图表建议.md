# Energy、Energy Conversion and Management、Applied Energy 投稿图表规划

日期：2026-10-21。

本方案以现有2022年8760小时、风光各200 MW、年产氨80,000 t的同一装置模型为基础。比较对象为成本优先参考轨迹（设定值更新4029次）与487次经济合格可行轨迹。本轮仅核算已有结果和规划证据，没有新增优化或绘图。后续绘图沿用用户指定的MATLAB。

使用 nature-figure 的“一幅图回答一个科学问题”和 nature-writing 的“论点—证据—适用边界”原则。这里是能源工程研究论文的图表策划，不套用Nature期刊的图数、篇幅或投稿政策。以下7幅主图为建议架构，可按最终论证合并；不是三个期刊的硬性数量要求。

## 1. 应当围绕什么问题组织图表

建议核心问题：**在固定装置、同等全年产量和明确经济损失预算下，HB设定值更新需求可以简化到什么范围，其电—氢—氨协调方式和系统代价是什么？**

现有结果已支持：存在487次更新、全年满足原模型约束且经济损失不超过0.5 USD/t的调度。现有结果没有证明：487就是最低必要次数、该轨迹就是F(487)成本最优、储氢周转变化是所有少更新最优方案必有的机制。

| 术语 | 本方案的唯一含义 | 不混用为 |
|---|---|---|
| K或N(x) | 全年循环小时边上的HB设定值更新事件数 | HB启停数、实际负荷变化小时、疲劳循环 |
| 参考轨迹 | 某条成本优先的可行轨迹，计数4029 | 成本最优必需4029次 |
| 487次轨迹 | 满足经济预算的原模型可行见证 | 已证明固定K成本最优解 |
| F(k) | 更新次数不超过k时的最低年成本 | 任意一条k次轨迹的实际成本 |
| Keco(δ) | 相对真实最优成本增加不超过δ USD/t时的最少更新数 | 已找到的最少次数见证 |

## 2. 现有数据中最值得作图的发现

| 指标 | 参考轨迹 | 487次轨迹 | 观察到的变化与图意 |
|---|---:|---:|---|
| HB设定值更新 / 次 | 4029 | 487 | 减少87.9126%；相对的是这条参考轨迹 |
| 年成本 / USD | 31,747,636.6264 | 31,786,951.3844 | 增加39,314.7580 USD，即0.491434475 USD/t |
| HB实际负荷总变差 / p.u. | 618.135271 | 96.159777 | 减少84.4436%，是区别于更新计数的补充证据 |
| HB实际变化小时数 | 3943 | 1465 | 减少62.8455%；不等于K |
| HB最大实际小时负荷变化 / p.u. | 0.20 | 0.20 | 最大变化没有随次数降低 |
| AEL启动 / 模块台次 | 4788 | 3564 | 减少25.5639%，并未观察到更多AEL启动 |
| AEL启动用能 / MWh | 3591 | 2673 | 减少918 MWh |
| 购电 / MWh | 1635.402346 | 2377.190232 | 增加741.787887 MWh，45.3581% |
| 售电 / MWh | 224509.8 | 224509.8 | 两者均达到年风光可用电量20%的售电帽 |
| 弃电 / MWh | 19015.511558 | 20675.299445 | 增加1659.787887 MWh |
| 弃电率 / % | 1.693958 | 1.841817 | 增加0.147859个百分点 |
| 库存净变化等效周转 / 次 | 238.375387 | 266.208942 | 增加11.6764%；不解释为储罐疲劳循环 |

两者全年小时加权平均HB实际负荷均为80%，月均最大绝对差仅0.876594个百分点。**月均负荷很接近，仍可以对应完全不同的小时调整结构**，所以月均图不宜承担“更新需求显著下降”的主证据。

年度电量差值满足

\[
\Delta E_{\rm curt}=\Delta E_{\rm buy}-\Delta E_{\rm start}
=741.787886891-(-918)=1659.787886891\ {\rm MWh}.
\]

该关系与直接计算的弃电差值偏差约1.17×10⁻⁸ MWh；AEL生产用电、HB用电和全年售电基本相同。这是能量守恒与分配的证据，不能单凭恒等式判断新增购电“导致”弃电。

本算例购电价为53 USD/MWh，弃电罚金为0，启动用能经电力平衡结算，其他成本分项基本相同，故

\[
\Delta C=741.787886891\times53=39,314.758005\ {\rm USD}.
\]

不能再将918 MWh启动用能下降按电价另加一次货币收益。大额固定费会淹没成本差异，优先画增量成本而不是两根完整总成本大柱。

## 3. 建议主图顺序与每幅图的证据任务

### 图1：系统边界、更新定义与经济预算

**问题：研究究竟在优化什么？**

- a：风光—电网—AEL—储氢—HB的系统结构，标明容量固定、全年产量固定、能量和物质流。
- b：用一段真实轨迹展示HB设定值阶梯、实际负荷、±0.005跟踪带及更新边；完整8760小时的循环边界在图注说明，不把所有实际变化均算作更新。
- c：定义C*、F(k)和Keco(δ)，标明δ=0.5 USD/t对应40,000 USD/a预算。

现有模型和数据即可完成。系统示意保持二维、简洁，不添加模型没有的温压动态或寿命模块。此图提供研究定义，不承担新颖性证明。

### 图2：经济可达性与最低更新需求的认证边界——论文核心图

**问题：少更新方案是否满足经济要求，最低需求知道到什么程度？**

- a：展示参考轨迹与487次见证的成本—次数位置，预算线标在0.5 USD/t。当前只有两条轨迹时保留孤立点，不连接为最优前沿。
- b：展示Keco的已排除区、未判定区和已有经济可行见证。阶段若采用[406,487]就统一全文；采用已验收的更强[408,487]时需对应证书版本。左侧被排除的是经济合格性，不等同于物理不可行。
- c：另行展示参考成本和固定次数成本的上下界，或作为紧邻表格。两个维度的不确定性不混在同一根误差棒内。

当前可以画“已知证据图”；完整F(k)曲线或δ—Keco关系需要补充优化。横轴若表示更新预算，应写“maximum allowed updates k”，不写成每条解实际恰有k次。

经济区间必须区别：487见证相对真实C*的溢价在[0.491434475,0.491716179] USD/t；而F(487)目前的保守包络为[31,747,614.0901,31,786,951.3844] USD。前者窄区间只反映参考最优成本不确定性，不能拿它表示F(487)已经求得很精确。

### 图3：全年调整结构及平台分布

**问题：同样年度生产任务下，调整在时间上如何被简化？**

- a、b：参考与487次方案的全年HB实际负荷日×小时热图，同一色标和时间轴；设置独立的更新事件带，避免仅凭负荷色块推断K。
- c：循环设定值平台持续时间的经验累积分布，两方案都使用全年全部平台，跨年平台按循环定义合并。
- d：更新幅度分布，辅以实际负荷总变差和最大实际小时变化的标注，用于检查“更少但更大的调整”。事件数不同，分布需明确按事件归一化；必要时同时报告事件总数。

无须新优化；需从原始参考解补导出与487次一致的全年字段并按统一规则后处理。平台不是恒定实际负荷：实际负荷仍允许在跟踪带内波动。不用直方图的平滑程度替代工程结论。

### 图4：同一关键时窗的电—氢—氨协调

**问题：少更新方案在小时尺度上怎样维持生产与库存平衡？**

两列对应参考与487次方案，共享日期和纵轴量程；建议依次显示可再生出力、HB实际负荷及设定值、AEL制氢/功率、氢库存。必要的购电或弃电时段用小面板补充，避免在一个轴上堆叠所有变量。

时间窗按输入数据预先定义，例如全年平均可再生出力最低的连续168小时窗口；可在SI加入高出力窗口。两方案使用同一时间窗并说明选择规则，不能分别选择各自最好看的周。关键周是全年机制的例证，需图3的全时段证据支撑。

无须新优化，但需补齐参考轨迹的AEL和库存字段。当前已有487次单方案关键周图不能直接视作公平比较图。

### 图5：运行简化的能量、经济与设备活动代价

**问题：少更新伴随的系统代价和收益分别在哪里？**

- a：年度电量差值闭合图，显示启动用能−918 MWh、购电+741.788 MWh、弃电+1659.788 MWh及其他不变项。
- b：成本增量分解，显示新增购电与总增量的对应关系；注明当前电价、售电帽和零弃电罚金条件。
- c：库存净变化等效周转与AEL模块启动的配对比较，明确有的活动指标下降、有的上升。

现有结果即可完成。购电增加45.36%应同时给绝对量，避免低基数造成夸大。库存工作范围不变，不能由周转增加推出必须扩容或寿命降低。购电相关排放是新增购电乘相同排放因子的派生结果，可放表格，不必重复占主图；不能称完整生命周期碳足迹。

AEL统计为模块台次，模型初始在线数为0、末态未要求循环，两轨迹末态在线数也不同；图注和方法必须保留这一边界，不能将台次下降直接解释为整厂启停或设备生命周期改善。储氢“净变化等效周转”来自库存净变化半总变差，可能掩盖小时内同时进出，不是完整实际双向流量测量。

### 图6：储氢与经济预算的受控边界

**问题：上述简化能力由哪些系统条件限定？**

优先以储氢工作容量与经济预算为两个轴，显示Keco的认证区间或已知见证，未判定格明确留空/标记。也可从储氢减小、基准、增大三个受控条件开始，再扩展预算点，不预设热图必须填满。

这幅图需要新的、同口径的反事实优化，目前不能由两条轨迹或旧储氢扫描直接作结论。旧扫描需先核对模型版本、目标、计数定义及经济基准，不默认可复用。

经济帽必须明确比较问题：各容量相对自身C*设帽，回答各配置自身近优区域的简化能力；共享基准配置的绝对成本帽，回答同一经济要求下配置的替代能力。两者不可混用。若讨论扩容投资，应计入新增年化成本。先改变一个资源边界并重新优化，再判断库存触界是否与更新需求存在因果联系。

### 图7：公平基线及适用范围

**问题：结果是否超出一条任意参考解，并能否用于可信决策？**

建议将成本优先参考、参考成本精度范围内进一步减少更新的方案、周期窗口策略、总变差平滑策略与本方法比较。各策略需在原模型下核验，统一产量、输入、跟踪带和成本口径；周期窗口不固定一个不利相位来制造优势。

若比较“相同0.5 USD/t经济预算下谁的更新少”，所有方法采用同一经济帽。若比较“最低成本优先与少更新优先的目标差异”，则分别明确其成本容许范围。将0.5 USD/t帽内再最小化K作为同一优化目标时，本质就是Keco问题，不能换名充当独立对照。

成本—实际更新数散点附目标上下界，超帽或不可行结果如实标注。另选一项与论文主张最相关的外部条件检验，如另一风光年度、产量强度或电网限制。若声称在线可实施性，再考虑滚动/有限预知验证；确定性年度规划论文不必机械扩展为所有不确定性方法。

此图需要新对照证据。没有公平计时和跨算例性能时，求解器收敛曲线及21项探索主要进入SI；只有将计算方法作为核心贡献时，才提升直接MILP与有效下界消融到正文。

以下前一列依据出版社官方范围，后一列是对本项目的投稿策划判断，不代表编辑的具体录用标准。

| 期刊 | 官方范围中的相关重点 | 本项目优先强化的图与论证 |

| Energy | 集成能源系统、能源规划与管理、系统级储能、氢与能源载体及跨部门系统 | 图2、3、5说明同等生产任务下的年度计划简化及系统代价；图6/7补充边界，使结果超过单一年份案例 |
| Energy Conversion and Management | 能量转换/储存/运行/控制以及适当验证；明确指出仅应用或比较现有优化方法、或小幅方法变体通常不足 | 图4、5、6突出HB—AEL—储氢—电网的协调与受控机制；不能仅以MILP求解及方法试验列表充当贡献 |
| Applied Energy | 应用导向、多能源耦合、氢与可持续燃料、柔性和决策，并鼓励衔接研究与实施 | 图2、6、7突出可核验的决策边界、公平基线、适用条件；用图4/5说明系统后果，实施性主张应有相应验证 |

不能仅通过增加图数改变稿件的新颖性。Energy同样需要有意义的系统发现；ECM不要求机械添加现有模型没有的热力学/火用分析；Applied Energy也不意味着必须同时建立随机、鲁棒和滚动优化三套框架。

当前这两条轨迹可支撑“案例中的少更新经济可达性及运行分配差异”，尚不足以单独支撑三刊完整投稿论证。最值得补强的是明确预算下的最低需求证据、相对于公平基线的增量，以及至少一项受控边界；不必先把每一个k都求到精确最优。

## 6. 与已发表工作的差异应如何体现在图里

Wu等2024年ECM论文已经研究合成氨负荷范围、调节速度与调节频率对成本和容量的影响。[4] 因此“考虑柔性”“调节频率影响经济性”“用MILP协同调度”不宜单独列为核心新颖性。

本项目更有依据的图表主线是：**固定装置与同等年产量 → 明确经济预算 → 最低事件数的可行见证与排除范围 → 受控资源边界下这一需求如何移动**。这要求图2和图6承担实质证据，不能仅展示4029与487的巨大柱高差。

参考4029可能受成本问题多解影响。优先检查在参考成本精度附近减少更新后，基准计数会不会大幅下降；这关系到87.9%降幅应如何解释，比美化现有柱状图更重要。

## 7. 执行顺序与统一作图口径

1. 先用现有解完成图1、3、4、5；仅补导出和后处理，不需要新优化。图2先制作已知证据版本。
2. 新优化优先服务图2的代表性预算/次数点、图7的基线公平性，以及图6的一项受控资源边界。取点由待回答问题决定，不安排没有目的的密集扫描。
3. 正文明确当前487轨迹未证明固定K成本最优。若研究不同k的最优系统参数变化，应尽量收紧固定k成本界；即使成本很接近，轨迹也可能多解。对关键参数采用统一次级目标或近优范围分析，避免求解器任意选解造成伪趋势。
4. 不确定性分开画：MILP目标界是优化证明区间；Keco的左右端是阈值未判定范围；HB月内分位是小时分布；风光跨年变化是情景差异。不能统一命名为统计置信区间，更不将8760个相关小时当独立实验重复。
5. 英文论文采用英文标签、统一灰色参考/蓝色487、跨方案同一色标与单位。优先二维配对图、ECDF、同步时间序列、差值分解和带证据状态的边界图；不用雷达图拼接不同量纲，不用三维曲面填补未知点。
6. MATLAB保留.m、.fig、矢量PDF和精确源表，导出后检查最终尺寸、字体、对齐、裁切和碰撞。既有600 dpi PNG可作预览；最终格式按选定期刊最新Guide for Authors再次核对。
